# Project Title: Enterprise Sales Performance & Financial Analytics Dashboard using Microsoft Excel

## Problem Statement
An enterprise requires an automated reporting system that consolidates sales, finance, and operational data into a centralized dashboard for executive decision-making. 

## Objectives
- Build automated ETL workflows.
- Develop financial models.
- Create KPI dashboards.
- Generate executive reports.
- Deliver business recommendations.

## Features 
- Power Query ETL
- Power Pivot Data Model
- Dynamic Dashboard
- Forecasting
- Budget Analysis
- KPI Cards
- Executive Summary
